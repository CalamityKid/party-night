This is a python console narrative game in which you try to enjoy a really bad party using the power of friendship, flirting and chemical helpers.
You navigate using input next commands and as you choose actions time passes, the music changes and the party becomes more crowded. 

This game is inspired in the pre-pandemic queer parties that used to be held in Sala Tango in Barcelona. 
How bad the music was and how much fun we had despite of it.
The whole game is written in gender neutral language.

There are set events that happen at specific times, but it is up to you to decide who or what you want to spend your time on.
After the party ends, at 6 am or if you decide to leave, you get a summary of how much you bonded with each friend.
I hope you enjoy it.
